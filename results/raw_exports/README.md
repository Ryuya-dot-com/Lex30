# Raw Browser CSV Exports

Place participant CSV files downloaded from the Lex30 browser app here. These
CSV files are the primary input for `tools/run_pilot_analysis.py`.

Keep participant JSON downloads as raw archives too, but do not rely on them as
the primary batch-analysis input unless you first recover them with
`tools/recover_browser_backup.py`.

Do not edit raw exports in place. Use manual override CSV files during scoring
when spelling corrections are justified after review.
